# How to Name Your Telegram Bot

You tried "Billionaire Path" and the username was taken. Here's how to handle it.

---

## Understanding Telegram Bot Naming

**Two separate names:**

1. **Display Name** - What users see (can be anything, even duplicates allowed)
2. **Username** - Must be unique across all Telegram (ends in `bot`)

Example:
- Display Name: "Billionaire Path" ✅ (can reuse)
- Username: `billionaire_path_bot` ❌ (taken)
- Username: `saptarshi_billionaire_bot` ✅ (unique)

## How to Rename Later

Can't change username once created. But you can:

1. Create new bot with better name
2. Export database from old bot
3. Import to new bot
4. Delete old bot via @BotFather (`/deletebot`)

Not recommended mid-use, but possible.
