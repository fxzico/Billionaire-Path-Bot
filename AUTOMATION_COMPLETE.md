## 🚀 Deploy in 3 Steps

### 1. Get Anthropic API Key (30 seconds)
https://console.anthropic.com/settings/keys
- Click "Create Key"
- Copy it (starts with `sk-ant-`)

### 2. Add Key to `.env` (15 seconds)
Open `.env` in this folder, replace:
```
ANTHROPIC_API_KEY=your_anthropic_api_key_here
```
with your actual key.

### 3. Run Deploy Script (15 seconds)
**Windows:**
```bash
deploy.bat
```

**Mac/Linux:**
```bash
chmod +x deploy.sh
./deploy.sh
```

That's it. Bot will be live in 2 minutes.
