# 🎯 NEXT 60 SECONDS

## Step 1: Get Your API Key (30 seconds)
1. Open: https://console.anthropic.com/settings/keys
2. Click "Create Key"
3. Copy it (starts with `sk-ant-`)

## Step 2: Add It to .env (15 seconds)
1. Open `.env` in this folder
2. Find line: `ANTHROPIC_API_KEY=your_anthropic_api_key_here`
3. Replace `your_anthropic_api_key_here` with your key
4. Save

## Step 3: Deploy (15 seconds)
Double-click: **`deploy.bat`**

That's it. Your bot will be live in 2 minutes.

---

## What Happens Next

The script will:
1. Install Railway CLI
2. Log you into Railway (opens browser once)
3. Create a project
4. Upload your bot
5. Start it

You'll see:
```
✅ Deployment complete!
Your bot is live at: t.me/Zico_Billionaire_Path_bot
```

Then:
1. Open Telegram
2. Search: `@Zico_Billionaire_Path_bot`
3. Send: `/start`
4. Send: `/log`
5. Type your first entry

Done.
